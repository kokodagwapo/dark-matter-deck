# Dark Matter — keynote web deck

Hero-only animated HTML version of the keynote (38 full-viewport slides).

## Present
Open `index.html` (or the GitHub Pages URL). → / Space / click = next, ← / click left third = previous,
Home/End, type a number + Enter to jump, F = fullscreen, N = speaker notes, ? = shortcuts.
Deep link to a slide with `#12`.

## Edit
Press **E** (or the Edit button, or open with `?edit`). Click any text and type.
Edits auto-save in your browser. **Export HTML** downloads an `index.html` with your edits baked in:
replace `index.html` in this repo with it (GitHub → Add file → Upload files) and the live site updates.
**Export edits / Import** move edits between browsers as JSON. **Reset** discards local edits.
